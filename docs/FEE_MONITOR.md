- 唯一主来源：https://www.binance.com/en/fee/stocks ，直接美股及 ETF，不是代币化股票或加密交易。
- Codex 当前聊天定时任务 `automation`，每天北京时间 09:00。无变化不通知；变更或首次无法核查时通知。桌面运行和系统通知权限影响任务与系统弹窗，不能视为服务器独立定时任务。

## 每日操作（已授权）

1. 读取 `data/fee-observation.json` 与 `var/fee-watch.json`。通过浏览工具打开唯一官方主来源，核实完整费用条款。保留结构和说明文字；仅真实条款变化才改 terms，避免措辞变动导致误报。
2. 仅在成功读取完整来源后更新 `checked_ms`（当前 UTC 毫秒）和确实变化的条款。规则包含生效/截止时间，未来 VIP 规则不能提前应用。促销在 UTC 截止时间之后不再有效。
3. 执行 `python scripts/update_fee_watch.py data/fee-observation.json`，然后 `python scripts/publish_fee_watch.py`。后者使用 `C:/Users/xl246/.ssh/obr_math_ed25519` 专用密钥和严格主机校验；不需要币安 API Key/Secret。
4. 同步服务器失败时明确报告，不能宣称项目弹窗已同步。来源读取失败时不更新时间或覆盖旧成功记录。超过 26 小时接口返回 STALE，页面显示过期状态。
5. 对条款变化或已到生效/失效日期的规则变化，给出原值、新值、北京时间和官方链接。无变化不通知。
