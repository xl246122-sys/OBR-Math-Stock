# 模拟账户配置进度（2026-10-31）

用户确认默认初始资金 600 USD、单笔预算上限 300 USD、同时持仓最多 2 笔；支持自定义。费用必须动态依据币安官方美股规则。

## 已实现（本地，尚未发布服务器）

- `data/paper.example.json` 是配置模板，设置环境变量 `OBR_PAPER_CONFIG_FILE` 为配置文件绝对路径后启动服务即可加载；不设置则采用上述默认值。
- 金额用 Decimal；单笔预算包括买入费用，不得超过初始资金。配置中的持仓上限允许 1–5，默认 2。错误配置拒绝启动。
- 资金配置通过受鉴权的状态和持仓接口展示。初始资金只表示新模拟账户的起点，不是已有账户余额。
- 模拟执行器统计实际持仓及待成交买单占用名额；撤单状态不明仍占名额。部分成交后撤单只释放未成交资金，已持仓仍占名额。
- 上限随模拟账户快照保存与恢复，旧快照缺少该字段时采用 2。
- 69 项测试通过，包含配置校验、部分成交、未知撤单和重启恢复。
